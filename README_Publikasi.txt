STUDYFLOW WEBSITE PACKAGE
=========================

Isi:
- index.html: landing page StudyFlow dengan title, meta description, heading, fitur, FAQ, dan CTA unduh.
- assets/StudyFlow_Professional_Planner.xlsx: produk planner.

PENTING:
- Ini adalah website statis yang sudah disiapkan, tetapi BELUM online sampai kamu mempublikasikannya.
- Jangan mengklaim ada trafik, pengguna, leads, atau penjualan sebelum ada data nyata.
- Keyword yang dipakai di title/deskripsi adalah hipotesis awal. Verifikasi dengan Google Autocomplete/related searches dan simpan screenshot sebagai bukti riset.

Cara publikasi gratis dengan GitHub Pages (jika menggunakan GitHub):
1. Buat repository baru bernama studyflow (public).
2. Upload index.html dan folder assets beserta file di dalamnya ke root repository.
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu Save.
6. Tunggu sampai GitHub menampilkan URL Pages. Jangan tulis URL sebelum benar-benar muncul.
7. Buka URL tersebut dan uji tombol unduh. Simpan screenshot halaman live sebagai bukti.

SEO dasar yang sudah disiapkan:

- File planner tersedia lewat CTA unduh.
